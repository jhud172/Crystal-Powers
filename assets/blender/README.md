# Original Crystal Powers assets

`build_assets.py` is the editable source recipe for the crystal and device collection. It runs in an isolated Blender process and does not touch an open Blender session.

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python assets/blender/build_assets.py -- --asset all
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --factory-startup --python assets/blender/build_assets.py -- --asset crystal --render --width 1920 --samples 96
```

Source scenes go in `assets/blender/scenes/`; web GLBs and rendered stills go in `frontend/public/models/` and `frontend/public/renders/`. Open the saved `.blend` file to edit geometry, studio lights, cameras, materials and animation. Re-running the recipe replaces only its named generated outputs.

Device screens use named `Screen` meshes and UVs so the website can replace their material with project screenshots. Device roots use metres and export Y-up through Blender's glTF exporter. Animation actions are named `CrystalTurn` and `LaptopOpen`. Critical product text remains HTML, outside the canvas.

All geometry is original to this project. No paid assets, downloaded models or external generation services are used. Rendered optical effects are intentionally richer than their real-time material equivalents. Validate both separately.

## Aurora crystal sculpture (2.0)

`build_observatory.py` authors twelve twisted prismatic petals in two layers, twenty-four fine metallic inlays, three segmented orbital rings, six satellite jewels and a luminous cut core. Twenty-two pivots animate with staggered minimum-jerk easing over 58 frames at 24 fps (approximately 2.4 seconds). Original mineral striations are generated deterministically into a packed texture; six glTF-compatible pigment factors preserve the colours. `observatory.glb` retains the `CrystalOpen` and `CrystalClose` contracts. Closed/open dark/light `.blend` scenes and PNG/WebP posters remain editable and reproducible. Legacy crystal/device assets are preserved.

The saved photography scenes mute both overlapping NLA tracks to retain their explicit rest/open pose. In Blender's NLA editor, enable the same named track on the twenty-two pivots to inspect that clip; keep the other named track muted. The exporter combines those tracks into separately named GLB animations. In the website, one paused opening action is scrubbed forwards or backwards with eased velocity, preserving the current pose when visitors reverse mid-gesture.

## Delivered outputs and regeneration

The current collection includes fourteen editable `.blend` scenes (legacy light/dark, cinematic and four Aurora poses), five self-contained GLBs, twelve rendered PNG poses, twenty-four responsive WebP posters and two six-second H.264 films (24 fps, 1280 × 800). The two default screen PNGs are captures of this website's earlier Crystal Powers page, not invented client work. Provenance, current hashes and decoded geometry evidence are in [ASSET_REVIEW_2_0.md](../../docs/ASSET_REVIEW_2_0.md).

After editing a saved dark scene, run `export_web_models.py` through isolated background Blender to regenerate all four web models. It exports custom properties: each device's `Screen` node must retain `role=project-screen` and its physical `aspect`. The browser uses those values to fit screenshots without distortion.

Run `python assets/blender/prepare_web_assets.py` to create the 800/1600-pixel WebP variants, validate geometry, screen metadata, animation, self-contained buffers and the 5 MB per-model limit, and refresh `frontend/public/models/manifest.json`.

Render either cinematic with `blender --background --factory-startup --python assets/blender/render_cinematic.py -- --appearance dark --width 1280 --samples 48` (or `light`). This is a full Cycles animation render and can take several minutes. The source recipe uses Blender 5.2's video output API and OptiX when available.

The largest delivered GLB is the optimised laptop at **1,063,912 bytes / seven meshes**, reduced from 1,322,404 / 104. Original scenes retain editable individual parts. `optimise_laptop_export.py` consolidates the exported untextured static groups without recalculating normals; hinge, screen, material factors and all 30,902 triangles remain. Regenerate the original from its scene after authoring changes, then validate a separate optimised candidate before promotion:

```powershell
python assets/blender/optimise_laptop_export.py --source frontend/public/models/laptop.glb --output .codex-runtime/qa/laptop-optimised.glb
python assets/blender/compare_laptop_exports.py frontend/public/models/laptop.glb .codex-runtime/qa/laptop-optimised.glb
python assets/blender/verify_model_geometry.py
python assets/blender/prepare_web_assets.py --validate-only
```

`--validate-only` validates existing posters and refreshes the manifest without re-encoding unchanged images. Omitting it retains the existing poster-generation command. Do not run broad model exports to update only one asset. The two films remain approximately 1.07/0.79 MB. Home warms its visible Aurora scene; other 3D stages and films require activation. One visible canvas and still/screenshot fallbacks remain essential. Local browser/rendering results and physical/hosted limits are in the current 2.0 progress/performance/asset reviews; older `REBUILD_QA.md` remains historical evidence.
