Support

A clear help path, not a maze of contact methods.

Support is intentionally simple. Use the contact page for project enquiries or request changes, and use the direct community channel when you already have an active delivery running.

Response expectations

Project enquiries
Use the site contact form with scope, timeline, and the problem to solve.
Active delivery support
Use the agreed support channel so updates stay attached to the current workstream.

03

Support changes stay inside the established structure: base layout, fragments, dedicated CSS, and dedicated JS.
