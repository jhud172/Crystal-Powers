# 24 - Feature Planning

## Purpose

Use before significant feature work or multi-file changes.

## Required Plan Fields

- Objective.
- User value.
- Affected routes.
- Affected files.
- Frontend impact.
- Backend impact.
- API impact.
- Data impact.
- Accessibility impact.
- Performance impact.
- Mobile impact.
- Testing plan.
- Rollback risk.
- Completion criteria.

## Rules

- Split large work into stages.
- Identify dependencies and ownership before editing.
- Avoid hidden API or route changes.
- Define non-goals.
- Keep scope practical.

## Validation

Before implementation, confirm the plan against actual code and current Git status.
