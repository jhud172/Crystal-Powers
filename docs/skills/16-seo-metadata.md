# 16 - SEO And Metadata

## Purpose

Use for page titles, metadata, search snippets, social previews, semantic headings, and structured data.

## Rules

- Use route-appropriate page titles and meta descriptions.
- Keep Open Graph and Twitter metadata accurate.
- Use canonical URLs where the app supports them.
- Avoid duplicate titles across routes.
- Preserve semantic headings and internal links.
- Use accurate alt text.
- Add structured data only where accurate.
- Do not invent ratings, project metrics, testimonials, or outcomes.
- Do not use old branding.

## Validation

Inspect `frontend/index.html`, route content, and any Spring template/static metadata touched by the task. Search for forbidden brand names.
