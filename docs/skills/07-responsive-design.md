# 07 - Responsive Design

## Purpose

Use for layout, navigation, typography, media, and interaction changes affecting viewport behaviour.

## Test Widths

- Narrow mobile.
- Standard mobile.
- Tablet.
- Laptop.
- Desktop.
- Wide desktop.

## Rules

- No horizontal overflow.
- No desktop-only interaction.
- No hover-only essential content.
- Touch targets must be large enough.
- Text remains readable.
- Avoid absolute positioning that breaks at intermediate widths.
- Avoid fixed heights for content-heavy sections.
- Avoid oversized heroes hiding CTAs.
- Simplify motion on mobile.
- Navigation must remain usable at all widths.
- Images must use responsive sizing.

## Validation

Check affected routes visually where practical. Report any viewport not tested.
