# Bug Fix Brief

## Symptom

What the user sees.

## Reproduction

Exact route, input, command, or sequence.

## Expected Behaviour

What should happen.

## Actual Behaviour

What happens now.

## Root Cause

Confirmed cause, not a guess.

## Minimal Fix

Smallest clean change that resolves the cause.

## Regression Test

Test or QA step that catches this bug later.

## Verification

Commands and manual checks run.
