# 25 - Final QA

## Purpose

Use before finalising significant work.

## Check

- All affected routes.
- Navigation and mobile menu.
- Themes.
- Three.js hero if touched or impacted.
- WebGL fallback if touched or impacted.
- Reduced motion.
- Keyboard navigation.
- Contact form and validation if touched.
- Browser back and forward.
- Direct URL loading.
- 404 route.
- Console errors where browser access is available.
- Network errors for API changes.
- Horizontal overflow.
- Build output.
- Backend tests.
- Branding search.
- Dead code and unused dependencies.
- Documentation updates.

## Rules

- Do not run full builds for documentation-only changes unless needed.
- Run full verification for significant application changes.
- Report skipped checks and why.
- Confirm no unrelated files changed.

## Reporting

Summarise changed files, commands, results, warnings, failures, and remaining risk.
