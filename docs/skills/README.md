# Crystal Powers Skills

This folder is a repository-local skill system for future Codex sessions. It keeps project-specific rules close to the code so work stays consistent across frontend, backend, design, testing, performance, accessibility, security, and deployment.

## How To Use

## Updating Skills

When architecture changes, update the smallest affected skill file and any relevant template. Keep guidance concise, specific to Crystal Powers, and aligned with actual code. If documentation and implementation disagree, inspect the code and update the stale document.

Templates live in [templates/](templates/).
