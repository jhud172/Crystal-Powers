# Clean Theme Audit

## Style Direction

Clean should feel bright, precise, airy, and product-led. It is the least dramatic theme and should make the interface feel lighter without losing Crystal Powers polish.

## Palette

- Base: pale blue, white, and soft cloud surfaces.
- Accent: clear blue and light cyan.
- Avoid: heavy shadows, black-heavy panels, or saturated neon.
- Text: ink/navy for strong readability.

## Assets

- Home atmosphere: `/images/themes/clean-atmosphere.svg`.
- Portfolio feature atmosphere: `/images/themes/clean-atmosphere.svg`.
- Brand mark: crystal UFO logo, kept crisp through light media treatment.
- WebGL crystal: white, blue, ice, and soft cyan facets.

## Navbar Rules

- Navbar should read as frosted light glass.
- Shadows should be softer and more diffuse than Futuristic.
- Active states should be clear blue, not heavy glow.
- CTA may remain dark for contrast, but should not overpower the clean surface.

## Audit Checklist

- Navbar token overrides produce a visibly lighter shell.
- Text contrast is checked against light panels.
- Mobile menu remains legible and does not become washed out.
- Hero/media assets swap to clean atmosphere artwork.
- Focus rings are strong enough on light backgrounds.
