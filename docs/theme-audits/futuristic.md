# Futuristic Theme Audit

## Style Direction

Futuristic is the default Crystal Powers identity: cinematic, orbital, glassy, high-contrast, and technology-led. It should feel like a premium digital command surface rather than a generic dark mode.

## Palette

- Base: deep navy and near-black surfaces.
- Accent: cyan, electric blue, and controlled violet.
- Warm note: small amber highlights are allowed only as secondary polish.
- Text: bright white headings, cool blue-white supporting text.

## Assets

- Home atmosphere: `/images/themes/futuristic-atmosphere.svg`.
- Portfolio feature atmosphere: `/images/themes/futuristic-atmosphere.svg`.
- Brand mark: crystal UFO logo.
- WebGL crystal: cyan, blue, violet, and white facets.

## Navbar Rules

- Keep the UFO underside visible and luminous.
- Command bar should feel like a floating sci-fi console.
- Active links can use strong cyan glow, but avoid excessive neon.
- CTA should stay dark, glossy, and high-contrast.

## Audit Checklist

- Navbar shell, links, CTA, theme picker, mobile menu, and UFO beam use theme tokens.
- Hero backdrops and media filters feel cool and futuristic.
- WebGL crystal colours match cyan/blue/violet lighting.
- Focus states remain clearly visible.
- Mobile navbar keeps the same command-surface mood without crowding.
