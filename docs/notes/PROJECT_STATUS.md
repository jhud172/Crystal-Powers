# Project Notes Status

Crystal Powers now uses React for the public website and Spring Boot for backend APIs.

Use the root `README.md` and `docs/PROJECT_STATUS.md` as the primary source of truth.

Current source boundaries:

- Frontend: `frontend/`
- Backend APIs: `src/main/java/com/crystalpower/website/api/`
- Web forwarding and legacy redirects: `src/main/java/com/crystalpower/website/web/`
- Backend services: `src/main/java/com/crystalpower/website/service/`

Do not add new Thymeleaf templates or root-level npm frontend builds.
